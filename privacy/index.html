Privacy Policy.

VenusToth Studio는 창작자의 영상과 연결 계정에 대한 제어권을 중요하게 생각합니다. 본 방침은 이 공식 웹사이트 및 로컬 Studio의 선택적 외부 서비스 연동과 관련한 개인정보 처리 원칙을 설명합니다.

01. 적용 범위와 운영 주체

VenusToth Studio는 독립적으로 운영되는 로컬 우선 AI 영상·음악 제작 프로젝트입니다. 본 방침은 공식 소개 사이트 및 Studio의 선택적 YouTube·TikTok 연동 기능에 적용됩니다. Studio는 사용자의 Windows PC에서 실행되며, 외부 AI 또는 게시 서비스 연동 시 해당 서비스의 별도 정책이 적용될 수 있습니다.

중요: 공식 소개 페이지는 GitHub Pages에서 제공되는 정적 사이트입니다. 이 웹사이트 자체는 회원가입, 로그인 또는 독자적인 광고 추적 시스템을 제공하지 않습니다. 호스팅 제공자의 기본 접속 로그 등은 GitHub의 정책에 따릅니다.

02. 처리할 수 있는 데이터

  • 제작 파일: 사용자가 직접 입력·선택하거나 Studio가 생성한 음악, 이미지, 영상, 가사, 자막, 프로젝트 설정과 렌더 결과는 기본적으로 로컬 작업 환경에 보관됩니다.
  • 연결 계정 정보: 사용자가 계정 연결을 승인하면 YouTube/Google 또는 TikTok에서 필요한 범위의 OAuth 토큰, 계정 식별자, 표시 이름, 승인된 권한(scope) 및 게시 상태 정보를 처리할 수 있습니다. 비밀번호를 직접 수집하는 방식이 아닙니다.
  • 업로드 정보: 사용자가 직접 게시를 선택한 MP4, 게시 제목·설명·해시태그, 공개 설정, 게시 결과 식별자 및 오류 기록이 해당 서비스의 공식 API를 통해 처리될 수 있습니다.
  • 로컬 진단 정보: 앱 동작 및 오류 복구를 위해 로컬 로그, 진행 상태, 작업 ID, 설정 및 미디어 경로 등이 저장될 수 있습니다.

연결 또는 업로드를 실행하지 않으면 외부 계정에 접근하여 영상 게시를 수행하지 않습니다. 앱의 개발 버전에 따라 제공 기능과 저장 위치가 달라질 수 있습니다.

03. 데이터 사용 목적

데이터는 사용자가 요청한 영상 기획·생성·편집·렌더링, 프로젝트 복구, 사용자 선택에 따른 YouTube/TikTok 계정 연결 및 동영상 전송, 게시 상태 확인, 오류 진단에 사용됩니다. 외부 계정 권한을 이용한 임의 자동 게시나 개인정보 판매를 목적으로 사용하지 않습니다.

04. 연동되는 제3자 서비스

TikTok Content Posting API

사용자의 명시적 승인과 서비스가 허용하는 범위 내에서 TikTok 로그인 및 업로드·게시 상태 조회 기능을 제공합니다. video.upload는 사용자가 TikTok 앱에서 게시를 마무리하는 방식이며, video.publish는 별도 승인 시 직접 게시에 사용됩니다. 게시된 콘텐츠는 TikTok 정책과 계정 공개 설정에 따릅니다.

TikTok Privacy Policy · TikTok Terms

YouTube / Google API Services

사용자가 YouTube 업로드를 선택하면 필요한 인증과 영상 메타데이터가 Google API를 통해 처리됩니다. YouTube API Services 사용에는 관련 서비스 약관 및 개인정보처리방침이 적용됩니다.

YouTube Terms of Service · Google Privacy Policy · Google 계정 연결 관리

GitHub Pages

이 공식 웹사이트는 GitHub Pages로 호스팅됩니다. 페이지 제공을 위한 접속 정보와 보안 로그 등의 처리는 호스팅 제공자의 정책을 따릅니다. 사이트에는 별도의 로그인·분석용 광고 스크립트를 설치하지 않았습니다.

GitHub Privacy Statement

05. 보관, 보안 및 전송

제작 원본과 프로젝트 설정은 사용자의 로컬 환경에서 관리됩니다. 연결 계정의 인증 정보는 기존 Studio 구현에서 사용하는 OS 기반 보호·토큰 관리 방식에 따라 저장됩니다. TikTok 계정 관련 로컬 인증 정보는 Windows 사용자 범위 암호화(DPAPI)를 사용합니다. 제3자 서비스로의 영상 전송은 사용자 선택과 해당 서비스 인증 후에만 수행됩니다.

로컬 파일과 작업 기록은 사용자가 삭제하거나 저장 구조가 변경될 때까지 남을 수 있습니다. TikTok·YouTube에 전송된 콘텐츠와 그 보관 기간은 해당 플랫폼에서 관리합니다. 계정 권한 철회만으로 플랫폼에 이미 게시된 영상을 자동 삭제하지는 않습니다.

06. 사용자의 선택 및 권리

  • 외부 계정 연결과 게시 여부를 직접 결정할 수 있습니다.
  • Google 계정의 연결된 앱 설정 및 TikTok 계정의 보안/앱 권한 설정에서 접근 권한을 철회할 수 있습니다.
  • 게시된 영상의 공개 범위 변경·삭제는 해당 플랫폼에서 직접 관리할 수 있습니다.
  • 로컬 프로젝트 및 인증 정보 정리는 앱에서 지원하는 기능 또는 운영자 문의를 통해 요청할 수 있습니다. 실행 중인 작업과 LOCK 결과물은 확인 후 안전하게 처리해야 합니다.

민감한 계정 정보, API 키, 접근 토큰, 실명·연락처를 공개 GitHub Issue에 기재하지 마세요.

07. 운영 문의 및 정책 변경

운영 주체: VenusToth Studio (독립 개인 개발 프로젝트). 제품 및 일반 지원 문의는 공식 홈페이지 GitHub Issues를 통해 남길 수 있습니다. 개인정보 관련 요청 시 공개 게시글에 개인정보를 올리지 말고, GitHub 프로필에 제공된 비공개 연락 수단이 있는 경우 이를 이용해 주세요.

실제 기능, 외부 API 정책 또는 법적 요구 사항이 변경되면 본 방침을 갱신하고 날짜를 표시합니다.
